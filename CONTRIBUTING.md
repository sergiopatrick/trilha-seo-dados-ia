# Como contribuir

Contribuições são bem-vindas, principalmente link quebrado, material melhor que o atual e correção de fato desatualizado.

## Link quebrado ou desatualizado

Abra uma issue com o arquivo, o link e, se souber, o substituto. Para conferir todos os links de uma vez, rode o script abaixo da raiz do repositório.

```bash
python3 ferramentas/checar_links.py
```

## Sugerir material

Abra uma issue ou um pull request respeitando os critérios da curadoria.
- Gratuito, ou pago e barato quando não houver equivalente livre. Informe o custo aproximado.
- Fonte primária antes de opinião.
- Atual. Nada que ensine prática descontinuada como vigente.
- Link aberto e conferido por você.
- Uma frase dizendo por que vale assistir ou ler.

## Estilo do texto

- Português do Brasil, frases curtas e diretas.
- Sem travessão e sem dois-pontos no texto corrido. Use ponto, vírgula ou parênteses.
- Casos reais só anonimizados, sem nome de empresa, de pessoa ou dado que identifique o cliente.
