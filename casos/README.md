# Casos reais

Situações vividas em projetos de consultoria de SEO, GEO e dados. Os nomes das empresas foram removidos e alguns números foram arredondados. O método e a lição são os mesmos.

Cada caso segue a mesma ordem. Contexto, sintoma, primeira hipótese, teste, causa, o que foi feito e lição. A primeira hipótese quase sempre estava errada, e é aí que mora o aprendizado.
